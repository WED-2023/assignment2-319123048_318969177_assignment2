Instructions:

You can move right, left, down, and up. There is a button to shoot. The goal of the game is to eliminate all the ghosts on the board and collect as many points as possible. Ghosts in the first row are worth 5 points, in the second row 10 points, in the third row 15 points, and in the fourth row 20 points. In each game, the player has 3 lives. After logging in, the user is directed to a configuration screen where they can choose movement keys and a shooting key, the color of the shots, background music volume, shooting sound volume, and game time. While playing, the top of the screen displays the score, remaining lives, time left, and a button to start a new game. When the game ends for any reason, a scoreboard is shown with two buttons: "Play Again" — starts a new game with the same configuration, and "New Game" — returns the user to the configuration screen. At any time, users can switch between screens using the buttons in the top menu.
